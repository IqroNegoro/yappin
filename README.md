# Yappin — Realtime Chat (Flutter + Firebase)

Aplikasi chat room realtime untuk praktikum Mobile Intermediate.
Branch ini (`app`) berisi aplikasi **lengkap**. Starter untuk mahasiswa ada di branch `main`.

## Menjalankan
1. `flutter pub get`
2. `flutter run` (emulator/HP) atau `flutter run -d chrome`
3. Tes realtime: buka di 2 device sekaligus, masuk ke room yang sama.
